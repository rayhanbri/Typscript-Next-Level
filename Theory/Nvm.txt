# What is NVM?

Node Version Manager (NVM) is a tool used to install and manage multiple versions of Node.js on the same computer.

---

# Why Do We Use NVM?

Different projects may require different Node.js versions.

Example:

* Project A uses Node.js 18
* Project B uses Node.js 22

Without NVM, managing these versions becomes difficult.

NVM allows you to:

* install multiple Node versions
* switch versions easily
* avoid compatibility problems

---

# Real Problem Without NVM

Suppose you install the latest Node.js globally.

Now an old project stops working because it only supports Node.js 16.

Without NVM:

* you must uninstall Node
* install another version manually
* repeat again for different projects

This is messy and time-consuming.

---

# How NVM Helps

With NVM:

```bash id="q8s5f1"
nvm install 18
nvm install 22
```

Switch anytime:

```bash id="o2u8z3"
nvm use 18
```

or

```bash id="u1p9e7"
nvm use 22
```

Very simple.

---

# Importance of NVM

## 1. Manage Multiple Node Versions

Main reason.

You can keep many Node.js versions together.

---

## 2. Project Compatibility

Some packages only work with specific Node versions.

NVM helps run projects safely without breaking them.

---

## 3. Easy Testing

Developers often test apps in different Node versions.

Example:

* test in Node 18
* test in Node 20
* test in Node 22

NVM makes this easy.

---

## 4. Cleaner Development Environment

No need to:

* manually uninstall Node
* reinstall repeatedly
* change system settings

---

## 5. Useful for Teams

In team projects, everyone can use the same Node version.

Example:

```bash id="ecy5cf"
nvm use 20
```

Now all developers work in the same environment.
