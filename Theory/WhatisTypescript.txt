# What is TypeScript?

TypeScript is a programming language built on top of JavaScript.

It adds **types** to JavaScript so developers can write safer, cleaner, and more maintainable code.

TypeScript code is converted (compiled) into normal JavaScript because browsers understand JavaScript, not TypeScript directly.

Example:

```ts
let name: string = "Rayhan";
```

Here, `string` is a type annotation.
It tells TypeScript that the variable must contain text only.

---

# Simple Definition

> TypeScript = JavaScript + Type Safety + Extra Features

If you already know JavaScript, learning TypeScript becomes much easier.

---

# Why Do We Use TypeScript?

Developers use TypeScript because JavaScript has some problems in large projects.

In JavaScript:

```js
let age = 20;
age = "twenty";
```

This is allowed, even though it can create bugs later.

But TypeScript catches the mistake immediately:

```ts
let age: number = 20;
age = "twenty"; // Error
```

So TypeScript helps developers find errors before running the application.

---

# Importance of TypeScript

## 1. Type Safety

The biggest advantage.

TypeScript checks data types during development.

```ts
function add(a: number, b: number) {
  return a + b;
}

add(10, 20); // Correct
add("10", 20); // Error
```

This reduces bugs.

---

## 2. Better Code Autocomplete

Editors like Visual Studio Code provide smarter suggestions.

Example:

* method suggestions
* property suggestions
* parameter hints

This increases development speed.

---

## 3. Easier to Maintain Large Projects

In large applications, many developers work together.

TypeScript makes code:

* more organized
* easier to understand
* easier to maintain

That is why big companies use it.

---

## 4. Helps Catch Errors Early

Instead of finding bugs after deployment, TypeScript shows many errors during coding.

This saves:

* time
* debugging effort
* maintenance cost

---

## 5. Better Readability

Types explain what data should look like.

```ts
function createUser(name: string, age: number) {}
```

Anyone reading the function immediately understands:

* `name` should be text
* `age` should be number

---

## 6. Great for Backend and Frontend

TypeScript is heavily used in:

* Frontend: React, Next.js, Angular
* Backend: Node.js, Express.js

You mentioned learning backend with Node.js + Prisma + TypeScript — TypeScript is extremely valuable there.

# Real-World Example

Imagine building an e-commerce app.

Without TypeScript:

```js
product.price = "500";
```

Someone accidentally stores price as string.

Later calculations break.

With TypeScript:

```ts
type Product = {
  price: number;
};
```

Now TypeScript prevents invalid data.

# Common Interview Question

## Q: Is TypeScript a replacement for JavaScript?

**Answer:**
No. TypeScript is a superset of JavaScript.
It compiles into JavaScript.

---

## Q: Does TypeScript run directly in the browser?

**Answer:**
No. Browsers run JavaScript. TypeScript must be compiled into JavaScript first.

---

## Q: What is the main benefit of TypeScript?

**Answer:**
Type safety and better developer experience.

---

# Common Misconceptions

## “TypeScript makes code run faster”

Not really.
TypeScript mainly improves development experience and code quality.

---

## “You must write types everywhere”

No.
TypeScript can automatically infer many types.

Example:

```ts
let city = "Dhaka";
```

TypeScript automatically understands this is a string.
